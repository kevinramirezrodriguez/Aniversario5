# Aniversario5 – cómo publicarla en GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo `aniversario5`).
2. Sube TODO el contenido de esta carpeta (index.html, manifest.webmanifest, sw.js y la carpeta icons).
3. En el repositorio: Settings → Pages → Source: "Deploy from a branch" → rama `main`, carpeta `/ (root)` → Save.
4. En 1–2 minutos tendrás un enlace `https://TU-USUARIO.github.io/aniversario5/`.
5. Ábrelo en el celular: Android/Chrome → menú ⋮ → "Instalar app"; iPhone/Safari → Compartir → "Agregar a pantalla de inicio".

## Editar textos
Abre index.html y busca "TEXTOS EDITABLES" (arriba del script): ahí están la carta, los 14 propósitos y las frases.
Si cambias el archivo y ya instalaste la app, sube también un nuevo nombre de caché en sw.js (`aniversario5-v3`).
